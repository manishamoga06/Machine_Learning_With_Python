# Sales Data Analysis Using Python

## Introduction

This is my second Python data analysis project. The project analyses sales data to understand product performance, monthly revenue and regional sales.

## Objective

To learn how Python can be used to analyse sales data, calculate revenue and identify useful information from a dataset.

## Tools Used

- Python – To write the program.
- Pandas – To load, manage and analyse sales data.
- Matplotlib – To create graphs and visualize sales information.

## Dataset Used

A sample sales dataset containing 20 records with the following details:

- Order ID
- Date
- Product
- Category
- Quantity
- Price
- Region

## Working of the Project

1. Loaded the sales dataset using Pandas.
2. Displayed the dataset and its basic information.
3. Checked for missing values.
4. Converted the date column into datetime format.
5. Calculated total sales using quantity and price.
6. Calculated total revenue and quantity sold.
7. Analysed product-wise sales.
8. Calculated monthly revenue.
9. Analysed region-wise revenue.
10. Created graphs using Matplotlib.

## Sample Results

- Total Revenue: ₹5,96,000
- Total Quantity Sold: 65
- Best-selling Product by Quantity: Mouse
- Highest Revenue Region: West

## Visualizations

The project generates three graphs:

1. Product-wise Sales
2. Monthly Sales Revenue
3. Region-wise Sales Revenue

## What I Learned

1. How to load CSV files using Pandas.
2. How to manage and analyse datasets.
3. How to calculate total revenue using Python.
4. How to use groupby() for data analysis.
5. How to identify best-selling products.
6. How to visualize data using Matplotlib.

## Difficulty Faced

Initially, I faced difficulty understanding how to group sales data and calculate revenue for different products and regions. I learned how to use Pandas functions to organize and analyse the data.

## Conclusion

Through this project, I learned the basics of Data Analysis using Python. I understood how to work with datasets, calculate sales information and represent results using graphs.
