# Student Performance Prediction Using Python

## Introduction

This is my first Machine Learning project using Python. The project predicts student marks based on the number of hours they study.

## Objective

To understand how Machine Learning can be used to predict marks using study hours.

## Tools Used

- Python – To write the program.
- Pandas – To create and manage data.
- Matplotlib – To display graphs.
- Scikit-learn – To create the Machine Learning model.

## Algorithm Used

**Linear Regression**

Linear Regression is used to predict marks based on study hours.

## Working of the Project

1. First, I created a dataset containing study hours and marks.
2. I converted the data into a table using Pandas.
3. I displayed the data using a graph.
4. I created a Linear Regression model.
5. I trained the model using the student data.
6. I entered study hours to predict marks.
7. Finally, I displayed the prediction graph.

## Sample Result

When I entered 6 study hours, the predicted marks were approximately 58.49.

## What I Learned

1. How to create a dataset using Pandas.
2. How to display graphs using Matplotlib.
3. How to create and train a Machine Learning model.
4. How to predict values using Linear Regression.

## Conclusion

Through this project, I learned the basics of Machine Learning and how to use Python for prediction. It helped me understand how a computer can learn from data and make predictions.
